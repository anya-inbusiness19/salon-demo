# Salon Site Demo

A sample salon website with online booking, a service menu, and a password-protected admin page.
Designed and built by A’Nya Hill · Project Sarae.

## Edit the site
1. Go to the site and add `#admin` to the end of the address (or tap **Admin** in the footer).
2. Log in with the admin password.
3. Make your changes and tap **Save changes**. An updated `index.html` downloads.
4. Upload that `index.html` to this repo (Add file → Upload files), replacing the old one. GitHub Pages updates in about a minute.

Bookings and messages in the admin are demo data saved in the browser you use.
